## Process notes (keep)

- Ledger timestamps written from memory drifted about two hours ahead of the wall clock on 2026-09-30 (14:05–19:50 entries); CI lines carry run id and sha, which are authoritative. Rule since then: timestamps from `date`.
- Two of three plan writers verified their code on scratch copies; the S3b parts were never executed before implementation. Rule: an implementer treats plan code as a draft to verify against the tests and reports corrections.
- Codex read-only comparisons with the sister (`gpt-6.1-sol`) found real defects at both the plan and the implementation stage (heredoc delimiter, symlinks, bounded diff read, worker diagnostics, unmeasured bottom-out, receipt size, `__proto__`, the check-then-unlink window). Keep the cadence: after each wave and before the release.
